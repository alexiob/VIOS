# Resident-system benchmark, 2026-10-16

Measured on the physical Agon Light 2 with the full VDP/USB resident profile, CPU image 72,292 bytes, SHA256 `4b78acad305ded1f349b8b4c86e313e74704ba85a5ff2fcd9148981a82951143`. All 45 conditions, 405 samples, engine results, medians and 25/50/100 scaling checks pass. Ordinary VM timing excludes transport output.

| Kernel, 100 iterations | C ticks | Token ticks | Direct ticks | Token ms | Direct ms | Direct time reduction |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| BM-ARITH | 11,123 | 2,441 | 2,133 | 8.476 | 7.406 | 12.6% |
| BM-BRANCH | 11,855 | 2,349 | 2,019 | 8.156 | 7.010 | 14.0% |
| BM-CALL | 7,608 | 1,725 | 1,488 | 5.990 | 5.167 | 13.7% |
| BM-LOOP | 4,566 | 1,183 | 1,050 | 4.108 | 3.646 | 11.2% |
| BM-MEM | 12,202 | 2,290 | 1,980 | 7.951 | 6.875 | 13.5% |

Direct threading uses 11.2–14.0% less elapsed time than token threading here. It is 4.35–6.16 times as fast as this build's C reference; that reference now includes additional transactional/native-service checks, so this ratio is not directly comparable with the earlier milestone. The checked native engines remain the normal execution path; C remains the semantic/test reference.

The nominal timer is 288,000 Hz. Results describe these five kernels in the current checked/profiled implementation. They do not establish the fastest threading technique for every workload, or a fully optimized release engine. See the [original measurement contract](README.md#measurement-profile).

Evidence: [raw transcript](../bring-up/vios-resident-accepted-run3.bench.txt), [validated samples](resident-2026-10-16.json), [board acceptance](../bring-up/vios-resident-accepted-run3.json).

Direct host-to-serial request medians over nine trials were 34.972ms for `DECIMAL 6 7 * . CR`, 42.154ms for inspection of `+`, and 50.929ms for resource inspection. These include framed transport, source CRC, echo, target work and result framing; they do not include an MCP/TCP client hop. Their different source and output sizes prevent direct comparison with the older raw-profile request measurements.
